# Product Context

## Why This Project Exists
Planted aquariums require precise, synchronized life-support systems:
1. **Light & CO2 Synchronization:** Plants need photosynthesis illumination aligned with CO2 injection to prevent algae blooms (especially Black Beard Algae - BBA).
2. **Night Aeration:** At night, plants consume oxygen instead of producing it; automated nocturnal aeration is critical for fish survival.
3. **Power Outage Protection:** Aquarium fish can suffocate within a few hours if aeration halts during power failures. The hardware UPS failsafe keeps aeration running in energy-saving pulses.
4. **Maintenance Ease:** One-tap Feeding Mode prevents food dispersion without needing manual cord unplugging.
5. **No Cloud Dependency:** Complete local control ensures the aquarium remains safe and controllable even if home internet is interrupted.
